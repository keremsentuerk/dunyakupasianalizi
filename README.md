2026 Dünya Kupası Öncesi Performans & Ekonomi Analizi
Bu proje, global futbol verilerini kullanarak takımların saha içi başarıları ile piyasa değerleri arasındaki ilişkiyi inceleyen 7 sayfalık interaktif bir Power BI Dashboard çalışmasıdır.

Araçlar: Power BI Desktop, DAX, Power Query.

Sayfa Sayısı: 7 Sayfa.

Veri Seti: [2026 Dünya Kupası takımları ve geçmiş turnuva istatistikleri.](https://www.kaggle.com/datasets/harrachimustapha/fifa-world-cup-team-dataset?resource=download)
